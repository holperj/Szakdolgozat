A DesignOffice Kft. egy középvállalat, amely ergonomikus, modern és testre szabott
irodabútorokat tervez, gyárt és értékesít. A cég fő tevékenysége három pillérre épül: a
tervezésre, a gyártásra és az ügyfélkiszolgálásra. A vállalat három külön épületben
működik, amelyek mind hálózati kapcsolatban állnak egymással.
A „DesignOffice” projekt hálózati infrastruktúrájához kapcsolódóan elengedhetetlen egy
olyan ügyféloldali interfész, amely reprezentálja a vállalat szakmai színvonalát. A
weboldal célja egy komplex értékesítési tölcsér (sales funnel) megvalósítása, amely a
látogatót az információszerzéstől a konkrét ajánlatkérésig és checkout folyamatig vezeti.
